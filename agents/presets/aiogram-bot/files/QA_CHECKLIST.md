# ✅ QA-чек-лист: Telegram-бот на aiogram (пресет aiogram-bot)

## Перед каждым merge
- [ ] `pytest` — все тесты зелёные; новые сценарии покрыты тестами.
- [ ] `ruff check .` и `black --check .` — без замечаний.
- [ ] Хендлеры не блокируют event loop (нет синхронных IO без `to_thread`).
- [ ] FSM очищается в конце сценария и на /cancel.
- [ ] `callback_data` парсится в роутере, формат `<feature>:<action>:<id>`.
- [ ] Токены/ключи — только из окружения; `.env` не в индексе.
- [ ] `alembic upgrade head` — миграции применяются чисто.
- [ ] `python agents/tools/check_integrity.py` — без ошибок.

## Надёжность (каждый релиз)
- [ ] Глобальный error handler: исключение в хендлере → лог + сообщение пользователю, бот не падает.
- [ ] Rate limit на пользователя (Redis) — флуд не ломает сценарии.
- [ ] Вебхук корректно настроен для прода; polling — только dev.
- [ ] Рассылки идут фоном с ограничением скорости (анти-спам лимиты Telegram).

## UX-проверка
- [ ] Каждый шаг сценария имеет кнопку отмены или инструкцию.
- [ ] Долгие операции отвечают «⏳» и продолжают в фоне.
- [ ] Тексты из `texts.py`, без дублей строк в хендлерах.
