# 🏛️ Оформление ADR

Решение: **$ARGUMENTS**

## Процедура
1. `python brain.py adr "$ARGUMENTS"` — создать карточку `agents/decisions/ADR_XXX_<name>.md`.
2. Заполни по шаблону `agents/templates/template_adr.md`:
   - **Контекст:** какая проблема/требование.
   - **Альтернативы:** 2–3 варианта с плюсами/минусами (включая «ничего не делать»).
   - **Решение:** выбранный вариант и ПОЧЕМУ именно он.
   - **Последствия:** что меняется, какие риски, как откатить.
3. Проверь пересечение с существующими ADR (`agents/decisions/`) — если новое решение их отменяет, явно укажи, какие.
4. Если решение архитектурно значимое — отрази его в `agents/architecture/SYSTEM_DESIGN.md`.

## Критерий качества
Через месяц новый агент должен понять решение из карточки, не перечитывая всю историю сессий.
