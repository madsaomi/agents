# 🏁 Передача сессии (handoff)

## Текущий контекст (автовставка)

### Активная задача:
!`cat agents/tasks/active_task.md`

## Чек-лист (выполни по порядку)

1. **Чек-лист задачи:** все выполненные шаги отмечены `[x]` в `agents/tasks/active_task.md`; незакрытые остались `[ ]` — это точка продолжения.
2. **План:** активный план в `agents/plans/` имеет актуальный статус (DRAFT/IN_PROGRESS/COMPLETED).
3. **Кодовая база:** если создавались/удалялись/переименовывались файлы — обнови `agents/architecture/CODEBASE_MAP.md`.
4. **Статус:** обнови дату и подсистемы в `agents/STATUS.md`.
5. **История:** `python brain.py end` — создай НОВЫЙ файл в `agents/history/`. Старые записи не перезаписывать и не удалять!
6. **Целостность:** `python agents/tools/check_integrity.py` и `python -m unittest discover -s tests` — без ошибок.
7. **Резюме пользователю:** что сделано / что осталось / первый шаг для следующего агента.

## Запреты (ANTI_PATTERNS)
- ❌ Не затирать историю сессий.
- ❌ Не закрывать задачу без верификации (тесты + check_integrity).
- ❌ Не оставлять «призрачную» работу без отметок в чек-листе.
