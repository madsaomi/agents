# 🐛 Триаж бага

## Шаг 1: Поиск по памяти
Прежде чем чинить — проверь, встречалось ли уже:
- `grep` по `agents/bugs_and_fixes/` с ключевыми словами симптома (имя файла, текст traceback, название модуля).
- **Найдено** → примени известное решение из карточки, не изобретай новое. Сообщи, какая карточка применена.

## Шаг 2: Классификация
Определи класс и укажи в карточке:

| Класс | Примеры |
|---|---|
| Код | логика, алгоритм, неверный вызов |
| Зависимости | версии пакетов, API сторонних библиотек |
| Окружение | ОС, пути, кодировки, Python-версия |
| Конфигурация | `.env`, настройки, хуки, CI |
| Инфраструктура | сеть, БД, Docker, права доступа |

## Шаг 3: Разбор
1. Воспроизведи минимальной командой.
2. Найди ПЕРВОПРИЧИНУ (где и почему), а не симптом.
3. Оцени регрессионный риск: какие тесты должны пройти после фикса.

## Шаг 4: Фиксация
`python brain.py bug "<Заголовок>"` → заполни карточку: Симптом → Первопричина → Решение → Правило предотвращения.

## Запреты
- ❌ `except: pass` и любое «тихое» проглатывание ошибок.
- ❌ Чинить симптом без устранения первопричины.
- ❌ Оставлять баг без карточки в `agents/bugs_and_fixes/`.
