# 🚀 Чек-лист релиза

Выполни по порядку, каждый пункт — с реальной командой/проверкой:

## 1. Верификация (обязательно)
- [ ] `python -m unittest discover -s tests -v` — все тесты зелёные.
- [ ] `python agents/tools/check_integrity.py` — 0 ошибок, 0 WARN.
- [ ] `python brain.py sync --check` — конфиги не разошлись с `agents/rules/CORE_RULES.md`.
- [ ] Линтеры проекта (если есть: `ruff`, `black`) — без замечаний.

## 2. Безопасность
- [ ] Нет секретов в diff: `git diff` — никаких ключей/токенов/паролей; `.env` не в индексе.
- [ ] Субагент **security-auditor** дал вердикт по изменённым конфигам/хукам/MCP.
- [ ] `.mcp.json` и `permissions` не расширяют права сверх необходимого (PostgreSQL — read-only).

## 3. Документация и память
- [ ] `agents/architecture/CODEBASE_MAP.md` отражает фактическую структуру файлов.
- [ ] `agents/STATUS.md` актуален; активная задача закрыта (`[x]`) или явно продолжается.
- [ ] Новые баги/решения в `agents/bugs_and_fixes/`, значимые выборы — в `agents/decisions/`.
- [ ] README/документация обновлены.

## 4. История
- [ ] Запись сессии создана в `agents/history/` (новый файл, старые не тронуты).

**Вердикт:** только при всех пунктах [x] — релиз разрешён.
