# 🧠 Second Brain Skill

> ⚠️ СГЕНЕРИРОВАНО `python brain.py sync` (зеркало для `.agents/skills/second_brain/`). Правь канон: `.claude/skills/second-brain/SKILL.md`.

Этот навык активирует поддержку методологии **«Второй Мозг» (Second Brain)** в текущем проекте.

## ⚡ Железные регламенты:
1. **Plan-First (Обязательно):**  
   НИКАКОГО КОДА БЕЗ ПЛАНА! Любые правки кода разрешены только после создания и согласования плана в `agents/plans/` (через `python brain.py plan "<Название>"`). Это принуждается PreToolUse-хуком.
2. **Параллельная фиксация:**  
   По ходу работы параллельно отмечай выполненные шаги `[x]` в `agents/tasks/active_task.md`.
3. **Фиксация багов и решений:**  
   Любые ошибки документируются в `agents/bugs_and_fixes/` через `python brain.py bug "<Ошибка>"`.
4. **Непрерывность сессий:**  
   В конце работы всегда сохраняй сессию в `agents/history/` через `python brain.py end`. Старые файлы истории никогда не удалять!
5. **Единый источник правил:**  
   Конфиги AI-инструментов генерируются из `agents/rules/CORE_RULES.md` — не редактируй их вручную, только `python brain.py sync`.

## 🛠️ Команды быстрого вызова (CLI):
- `python brain.py status` — дашборд состояния проекта.
- `python brain.py plan "Название"` — создать план реализации.
- `python brain.py bug "Ошибка"` — зафиксировать баг-репорт.
- `python brain.py adr "Решение"` — зафиксировать архитектурное решение.
- `python brain.py sync [--check]` — сгенерировать/проверить конфиги AI-инструментов.
- `python brain.py check` — проверить целостность Второго Мозга.
- `python brain.py dump` — скопировать контекст в буфер обмена.
- `python brain.py end` — завершить сессию и сформировать отчет.
